# NS Bus — автобусы Нови-Сада на карте

Веб-приложение в стиле «Яндекс Карт»:

* **Google-карта** (схема или спутник), все остановки Нови-Сада и пригородов.
* **Остановка**: список ближайших автобусов с обратным отсчётом (в минутах и в часах:минутах),
  отметками «онлайн» или «по расписанию», числом оставшихся остановок и номером машины.
  Автобусы видны прямо на карте.
* **Линия** (например, 7A): маршрут, проложенный по дорогам, с вкладками направлений,
  все автобусы на линии в реальном времени и вертикальная лента остановок с примерным временем прибытия.
* **Конкретный автобус**: пройденная часть маршрута показана серым, оставшаяся — цветом линии.
  Для каждой следующей остановки показано время прибытия, положение автобуса обновляется каждые 15 секунд.
* Поиск по названию остановки (латиница или кириллица) и по номеру линии, кнопка «Где я»
  с ближайшими остановками.
* Работает на ПК (боковая панель) и на телефоне (нижняя шторка). На Android приложение можно добавить на главный экран.

Данные берутся в реальном времени из того же API, которым пользуется приложение **NSmart** (`online.nsmart.rs`).
Маршрут по дорогам строит OSRM (OpenStreetMap), результат кэшируется в `cache/legs.json`.

## Как добраться (планировщик)

Нажмите синюю кнопку со стрелкой справа или «🏁 Как добраться?». Затем отметьте на карте, куда вам нужно.
Можно и так: долгое нажатие (правый клик) → «Маршрут сюда». Флажки **А** (откуда) и **Б** (куда) можно перетаскивать.
Варианты отсортированы от оптимального. Для каждого показаны: общее время, километры, время прибытия,
номера автобусов, пешие участки, ожидание (по живым данным NSmart, если автобус уже вышел на линию),
остановки посадки и выхода. Ищутся маршруты без пересадок и с одной пересадкой.

Пешие участки прокладываются по улицам, тропинкам и мостам. Для этого сервер один раз скачивает схему улиц
Нови-Сада из OpenStreetMap (около 10 МБ, примерно 30 секунд при первом запуске) и сохраняет её в `cache/walk_graph.pickle`.
Пока схема не загружена, расстояние пешком оценивается по прямой с поправкой.

## Язык

Переключатель **RU / SR** находится в шапке главного экрана и в меню слоёв. Интерфейс переводится полностью.
Названия остановок и линий не переводятся. Новости gspns.co.rs на русском переводятся автоматически
(Google Translate, перевод кэшируется). На сербском показывается оригинал.

## Ремонты и изменения трасс

Сервер берёт новости со страницы «Izmene u saobraćaju» на gspns.co.rs и показывает предупреждения
у линий, остановок и вариантов маршрута. В меню слоёв есть слой Google «Пробки и перекрытия».
Ремонты и закрытые улицы Google отмечает на нём значками. Данные о ремонтах из Яндекс Карт подключить
нельзя: у Яндекса нет открытого доступа к этой информации.

## Бесплатный хостинг (Render)

Файлы для GitHub собраны в папке `upload-to-github`. Пошаговая инструкция есть в ответе ассистента.

## Запуск на ПК (Windows)

Нужен **Python 3.8+**. Сторонние библиотеки не требуются.

Дважды щёлкните `start.bat`. Браузер откроется на http://localhost:8000.

Или вручную из командной строки:

```
python server.py            # порт 8000
python server.py --port 9000
```

## Запуск на Android

**Вариант 1: телефон и ПК в одной Wi-Fi сети (самый простой).**
Запустите `start.bat` на ПК. В консоли появится адрес вида `http://192.168.x.x:8000`.
Откройте его в Chrome на телефоне. Если Windows спросит про брандмауэр, разрешите доступ
в частной сети. Чтобы получить иконку как у приложения: Chrome → ⋮ → «Добавить на главный экран».

**Вариант 2: только телефон, без ПК (Termux).**
Установите Termux из F-Droid и скопируйте папку `novisad-bus` на телефон. Затем выполните:

```
termux-setup-storage
cd ~/storage/downloads/novisad-bus
bash start-android-termux.sh
```

После этого откройте `http://localhost:8000` в Chrome. В этом варианте работает и геолокация.

> Кнопка «Где я» в браузере работает только на `localhost` или по `https`. В варианте 1
> (адрес `http://192.168…`) Chrome её заблокирует. Если она нужна, откройте `chrome://flags`,
> найдите *Insecure origins treated as secure*, впишите туда адрес сервера и перезапустите Chrome.

## Как это устроено

```
server.py            — сервер на стандартной библиотеке Python:
                       /api/network   сеть остановок и линий (кэш 12 ч, cache/network_raw.json)
                       /api/arrivals  прибытия на остановку (прокси NSmart, кэш 12 с)
                       /api/vehicles  все автобусы линии (опрашивает несколько остановок по линии)
                       /api/route     геометрия по дорогам через OSRM (кэш на диске)
static/index.html    — интерфейс
static/app.js        — логика: карта (Leaflet + тайлы Google), остановки, линии, рейсы
static/app.css       — оформление
static/sw.js, manifest.webmanifest — PWA (установка на телефон)
```

Сервер нужен потому, что API NSmart не отдаёт CORS-заголовки, и браузер не может
обращаться к нему напрямую.

## Ограничения

* «Сейчас» (красным) означает прибытие меньше чем через 45 секунд.
  Серые пункты «по расписанию» — рейсы, автобус которых ещё не вышел на линию
  (так их показывает и NSmart).
* Точное время прибытия даёт NSmart только для выбранной остановки. Для остальных остановок
  на ленте маршрута время рассчитано по скорости автобуса, поэтому оно помечено знаком «≈».
* Цвета линий выбраны условно: в API NSmart цветов нет.
* API NSmart неофициальный (ключ встроен в публичное приложение NSmart). Он может измениться;
  описание API: [apollo4labs/gspns-api](https://github.com/apollo4labs/gspns-api).
* Тайлы Google подключены напрямую, без API-ключа. Для личного использования это работает,
  но официально Google это не поддерживает. Если тайлы перестанут грузиться, переключите слой
  на OpenStreetMap кнопкой слоёв.
